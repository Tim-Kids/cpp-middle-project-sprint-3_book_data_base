# cpp-middle-project-sprint-3_book_db (Хранилище книг)<!-- omit in toc -->


    В результате вы разработаете собственный контейнер с быстрым и удобным интерфейсом для работы с коллекцией элементов, а
    ещё вспомогательные функции и алгоритмы для работы с ним. В процессе вы будете применять концепты, свёрточные выражения
    и новые плоские контейнеры.

# Требования к результатам работы
## Обязательные требования
### Структуры данных и классы

    Реализованы два constexpr-конструктора для Book.
    Реализован std::formatter для Book.
    Реализован шаблонный класс-контейнер BookDatabase.
    Выбран эффективный и удобный контейнер для хранения имен авторов.
    Обеспечено эффективное хранение имён авторов в Book через std::string_view.
    Реализованы псевдонимы типов (например, iterator, const_iterator, AuthorContainer).

### Концепты и предикаты

    Реализованы пользовательские концепты (BookContainerLike, BookPredicate, и др.).
    Используются концепты для параметризации функций/методов.

### Функциональность

    Реализованы методы PushBack, GetBooks, GetAuthors.
    Реализована функция filterBooks для фильтрации по предикатам.
    Реализован предикат-фабрикаGenreIs.
    Реализована композиция предикатов all_of с использованием fold expressions.
    Реализована функция getTopNBy с возможностью изменять контейнер.
    Реализованы функции анализа:
        buildAuthorHistogramFlat
        calculateGenreRatings
        calculateAverageRating

### Тестирование

    Реализованы не менее трёх юнит-тестов для BookDatabase.
    Покрыты случаи пустой базы, граничные значения и некорректные входные данные.

### Использование современного C++

    Используются std::span, std::string_view, std::format.
    Используются transform, reduce, all_of и другие алгоритмы STL.
    Применяются std::flat_map, boost::flat_set и другие flat-контейнеры.
    Используются прозрачные компараторы для гетерогенного поиска.
## Технические требования
### В системе должны применяться:

    Ассоциативные, последовательные и flat-контейнеры.
    Шаблоны с концептами.
    Псевдонимы типов для обеспечения корректной работы контейнера BookDatabase со стандартными алгоритмами.

## Опциональные требования
### Функциональность

    Функция buildAuthorHistogram реализована без применения flat-контейнеров, а её производительность сравнивается с buildAuthorHistogramFlat на больших объёмах данных.
    Реализован метод EmplaceBack.
    Реализован конструктор BookDatabase с std::initializer_list.
    Реализованы предикаты-фабрики YearBetween, RatingAbove, GenreIs.
    Реализована композиция предикатов any_of с использованием fold expressions.
    Реализована функция sampleRandomBooks для случайной выборки книг.

### Архитектура и качество кода

    Соблюдается SRP.

### Тестирование

    Полное покрытие тестами класса BookDatabase, включая проверку существования псевдонимов типов.
    Покрытие юнит-тестами фильтров и предикатов (например, YearBetween, RatingAbove, GenreIs, filterBooks).
    Тесты для статистических функций (calculateGenreRatings, getTopNBy и др.).
    Тесты проверяют стабильность и производительность при больших входных данных.
